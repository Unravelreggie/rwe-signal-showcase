# Data and publication boundary

All identifiers use a `SYN-` or `DEMO-` prefix. Labels, dates, documents, rows and counts are invented solely for this public demonstration; they are not sampled, redacted, anonymized or transformed from operational data.

No clinical or business record, private case narrative, personal identifier, company/customer/product name, regulatory source passage, licensed terminology, original template, private endpoint, access token or original application file is included. No private Git history is imported.

The UI accepts only bounded demo controls. It has no file upload, authentication, persistence, external API, email, real workflow write or database connection. Source-document evidence inside the examples is represented by invented descriptive fields, not real document attachments. Product screenshots under `docs/previews/` are captured only from this independently written synthetic frontend. The static frontend is also published under the personal portfolio; it makes no connection to operational systems. Public methodology references, where included, are linked rather than bundled.

The original projects' capabilities and this demo's capabilities are distinguished in METHODS.md. Passing synthetic checks does not prove production completeness, clinical validity, regulatory compliance, or deployment security.
